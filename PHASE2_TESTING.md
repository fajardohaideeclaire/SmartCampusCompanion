# Phase 2 Testing Checklist

## Announcement Module Testing

### Functional Tests
- Announcements are successfully retrieved from the Room database.
- All announcements are displayed in the list correctly.
- The "Mark as Read" button updates the announcement status.
- The "Read" label appears after marking an announcement as read.
- Read status persists after app restart.

### UI & Usability Tests
- Announcement cards are properly spaced and aligned.
- Scrolling through the list is smooth.
- No UI overlap or layout issues occur.
- Buttons are clickable and responsive.

### Stability Tests
- No crashes occur when loading announcements.
- No crashes occur when marking announcements as read.
- No crashes during rapid scrolling or repeated clicks.
